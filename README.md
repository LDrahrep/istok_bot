# istok_rideshare — бот поиска попутчиков (v2)

Помогает водителям и пассажирам находить друг друга по **городу**, **штату**
(соседние города) и **отелю**. Один человек может быть и водителем, и
пассажиром одновременно.

## Что делает

- **🚗 Я водитель / 🧍 Я пассажир** — регистрация/обновление. Общие поля (имя →
  город → отель → телефон) спрашиваются один раз; водителю добавляются машина и
  число мест. Роли неразрушающие: добавил вторую — первая остаётся.
- Ввод максимально на кнопках; свободный текст только для имени, машины и
  телефона-вручную. Телефон — «📱 Поделиться» или ручной ввод с парсером US.
  Перед сохранением — **экран проверки** с правкой любого поля.
- **🔍 Найти** → кого (водителя/пассажира) → признак (🏙 город / 🗺 штат / 🏨
  отель) → любое значение (или «📍 мой») → результаты по 5, кнопка «Показать ещё».
  В карточке: имя, у водителя — машина и места, `t.me/username` (если есть),
  телефон.
- **📋 Моя запись** — просмотр; снять роль водителя/пассажира по отдельности
  (обе сняты → запись удаляется) или удалить полностью.

## Google Sheets

Одна таблица. Бот **пишет только в лист `people`**. Остальное ведёшь ты.

### `people` (источник правды бота) — заголовки в строке 1, регистр важен
```
Name | telegramID | Username | City | State | Hotel | Car | Seats | Phone | IsDriver | IsPassenger | UpdatedAt | isActive
```

### `cities` (ведёшь ты) — `City | State`
Список городов и их штатов. Отсюда кнопки городов; штат подставляется в запись
автоматически. «Соседние города» = один штат.

### `hotels` (ведёшь ты) — `Hotel | Address`
Без города (город и отель независимы). Поиск отеля при вводе текста идёт и по
названию, и по адресу.

### Две витрины для тебя (только чтение) — формулы

Создай листы «drivers» и «passengers» и вставь в **A1**:

```
drivers:     =QUERY(people!A:M, "select * where J = true", 1)
passengers:  =QUERY(people!A:M, "select * where K = true", 1)
```

(`J` = IsDriver, `K` = IsPassenger — 10-я и 11-я колонки `people`.) Диапазон
именно `A:M` по целым колонкам — `A1:M` Google принимает за имя и даёт `#NAME?`.
Обновляются сами; бот в них не пишет. Если у тебя разделитель аргументов — `;`,
замени запятые на точки с запятой:
`=QUERY(people!A:M; "select * where J = true"; 1)`.

## Переменные окружения (Railway)

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен нового бота от @BotFather |
| `SPREADSHEET_ID` | ID таблицы |
| `GOOGLE_CREDENTIALS` | JSON сервис-аккаунта целиком |
| `ADMIN_USER_IDS` | (опц.) ID админов через запятую |
| `PAGE_SIZE` | (опц.) размер порции, по умолчанию 5 |
| `PEOPLE_SHEET` / `CITIES_SHEET` / `HOTELS_SHEET` | (опц.) имена листов |

Сервис-аккаунт должен иметь доступ на редактирование таблицы (share на его email).

## Запуск

```
pip install -r requirements.txt
python bot.py
```

Деплой на Railway: `Procfile` → `worker: python bot.py`.

## Заметки по данным

- Телефоны хранятся как `+1XXXXXXXXXX` (US). Отображаются `+1 (XXX) XXX-XXXX`.
- `UpdatedAt` (UTC) пишется при каждом изменении; выдача поиска сортируется
  свежими вверх.
- Отель хранится по названию (по договорённости — отели не переименовываются,
  каждый в одном городе); адрес подтягивается из `hotels` для показа/поиска.
